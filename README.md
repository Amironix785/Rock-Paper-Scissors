# 🪨 Rock Paper Scissors ✂️

A simple **Rock Paper Scissors** game made with Python.

This project uses **Tkinter** to create the graphical user interface, **Pillow (PIL)** to load and display images, and **Pygame** to play the win and lose sounds.

The player plays against the computer, and the first one to reach **5 points** wins the game.

---

## 🎮 Features

- 🪨 Rock
- 📄 Paper
- ✂️ Scissors
- 🤖 Random computer choice
- 🏆 First player to reach 5 points wins
- 🔊 Win and lose sound effects
- 🖼️ Image-based graphical interface
- 👤 Player name input
- 📊 Live score display
- 🪟 Simple Tkinter GUI

---

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| Python | Main programming language |
| Tkinter | Creating the GUI |
| Pillow (PIL) | Loading and resizing images |
| Pygame | Playing sound effects |
| Random | Choosing the computer's move |
